# OneRingAI website

Read [AGENTS.md](AGENTS.md) and [README.md](README.md). This is the v2 static website, not the old Lexend theme. Source lives in `src/`; scripts generate `dist/`. GitHub Pages deploys after checks on `main`. Library documentation is generated from the pinned commit in `content/library.json`, using a gitignored source cache. Never edit generated cache/output or introduce branch-specific internal documentation links.
